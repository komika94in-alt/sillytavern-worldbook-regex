# 世界書 × 全域正則綁定

SillyTavern 原生 UI 擴充插件，**不需要酒館助手**。在世界書面板選擇器旁提供「正則綁定」按鈕。

- 全域世界書選區套用 A 世界書 → A 綁定正則加入**全域正則清單**，並啟用。
- 全域世界書選區卸下 A 世界書 → A 綁定正則從全域清單**移除**，完整快照保存在插件設定。
- 再次套用 → 從快照還原。修改過的正則會在卸下前更新快照。
- 多本世界書綁定同一個正則 → 任一本仍套用就保留；最後一本卸下才移除。
- 解除最後一個綁定 → 正則回到全域清單，交還手動管理。

判定只看**全域世界書選區**。在世界書編輯器查看一本書、角色／聊天／Persona 綁定、世界書條目關鍵詞觸發，都不算全域套用。

## 安裝

### 方式 A：本機安裝（不需要 GitHub）

1. 先備份現有全域正則，以及舊酒館助手腳本的變數。停用舊綁定腳本，避免兩套同步互相覆寫。
2. 解壓縮套件，將整個 `sillytavern-worldbook-regex` 資料夾放到：

   ```text
   SillyTavern/public/scripts/extensions/third-party/sillytavern-worldbook-regex/
   ```

3. 確認 `manifest.json` 直接位於上述資料夾，不要多套一層同名資料夾。
4. 重新整理酒館。擴充功能清單應出現「世界書 × 全域正則綁定」。
5. 打開世界書面板，在編輯器的世界書下拉選單旁點「正則綁定」。

這種放置方式是所有使用者可見的安裝；綁定設定仍隨各酒館使用者設定分開保存。若使用容器或遠端主機，必須放進**實際運行酒館的主機／持久化資料夾**，不是瀏覽器所在電腦的任意位置。

### 方式 B：Git 儲存庫網址安裝

1. 建立自己的 GitHub／其他酒館可存取的 Git 儲存庫。
2. 將本資料夾的**內容**放在儲存庫根目錄，至少包括 `manifest.json`、`index.js`、`core.js`、`ui.js`、`style.css`。不要上傳 `node_modules`。
3. 在酒館「擴充功能 → 安裝擴充功能」貼上該儲存庫的 HTTPS 網址。
4. 安裝完成後重新整理。

目前交付的是本機原始碼／ZIP，尚未發布到 GitHub，因此沒有可直接貼入安裝欄的公開網址。ZIP 也不是酒館助手可匯入的腳本 JSON。

一般安裝**不需要 npm，也不需要編譯**；`package.json` 與測試只供開發使用。

## 初次使用

1. 先把需要綁定的正則匯入酒館的**全域正則**。
2. 開啟世界書面板 →「正則綁定」。
3. 選世界書，勾選要綁定的正則，按「儲存並同步」。
4. 到「全域世界書」選區選取／取消選取該書，查看全域正則清單是否加入／移除。

儲存時，如果世界書尚未全域套用，剛綁定的正則會**立即從全域清單卸下**。它沒有丟失，可在綁定視窗看到「備份／已卸下」。世界書名稱與正則名稱不必相同，正則以 ID 關聯。

同一個被管理的正則只要對應世界書仍套用，就會維持啟用；手動停用／刪除它會被同步還原。若不想再自動控制，請解除綁定。

## 備份、舊版遷移與移除插件

- 「匯出已儲存備份」會匯出綁定及完整正則快照，不包含尚未按儲存的勾選。
- 「匯入備份／舊 v4」接受本插件備份，以及 `data.worldbook_regex_binder` 含完整 `regex.raw` 的舊 v4 腳本匯出 JSON。只讀 JSON 資料，不執行其中的腳本。
- 舊 v2／v3、缺少變數、缺少完整快照、非全域綁定不會猜測轉換。請先由舊腳本還原正則，再在原生插件重新綁定。**先保留舊腳本備份，不要直接刪掉。**
- 匯入採合併；同 ID 內容不同時會拒絕，避免覆寫現有正則。匯入需要獨立確認，確認後立即生效，主視窗的「取消」不會撤銷已確認的匯入。
- 解除綁定後仍保留庫內快照，供備份與再次綁定；不會僅因快照存在就自動管理未綁定正則。
- **停用或刪除插件前**，先匯出備份，再於綁定視窗取消「啟用自動綁定」並儲存。這會把卸下的綁定正則還原到全域清單，然後停止管理。直接在擴充清單停用／刪除，將無程式替你還原已卸下項目。
- 世界書改名不會猜測遷移。舊名稱會標示「不存在／已改名」，請先為新名稱勾選同樣的正則，再解除舊名稱綁定。不存在的書視為未套用，快照仍保留。

## 技術與相容性

- 直接讀取 `world-info.js` 的即時 ES module 欄位 `selected_world_info`。酒館重新指派陣列時仍讀得到新值，不讀延遲保存的 `world_info.globalSelect`。
- 監聽 `WORLDINFO_SETTINGS_UPDATED`，並以 1 秒低頻檢查補捉其他插件未發事件的變更。正常選區操作約 50 ms 後開始同步。
- 使用 `SillyTavern.getContext().extensionSettings.regex` 操作原生全域清單。綁定／快照保存於同一設定物件的 `worldbook_regex_native`，與清單變更一同交由酒館儲存。
- 原生正則欄位整份保存，包括替換內容、位置、深度、宏替換與自訂欄位；不套用酒館助手的欄位轉換。
- 目前酒館原生正則清單的重繪函式未公開。本插件在清單實際變更後發出原生 `CHAT_CHANGED` 事件，讓正則插件清快取並重建列表。**其他監聽此事件的插件也會收到通知**，這是已知相容性限制。
- 不會自動重新載入聊天，避免中斷生成。新生成／後續處理讀取更新後正則；既有訊息畫面若需重新套用，可自行重開聊天。
- 所有動態名稱以 `textContent` 顯示。沒有額外伺服器、遙測或外部網路請求；但你綁定的正則本身仍應來自可信來源。
- 依開發時官方 `release` 分支介面實作。內部模組可能隨酒館版本改動；不宣稱支援所有舊版、分支或第三方插件組合。若缺少即時選取欄位或資料損壞，會停止同步，不清空設定。
- 設定保存沿用酒館的延遲儲存機制；異常斷線／直接關閉頁面前未完成儲存的變更，仍可能未寫入磁碟。重要快照請另行匯出。

## 驗證

```sh
npm ci --ignore-scripts
npm test
```

測試涵蓋同步資料、快照、共用綁定、解除綁定、暫停／恢復、JSON 重啟、資料損壞、匯入衝突，以及 jsdom 主頁 DOM／面板／事件／儲存／取消流程。這是本機模擬測試，**不等於已在你的酒館實機驗證**。

實機驗收：

1. 建立測試世界書 A 與測試全域正則 A，並保留無關正則 B。
2. 綁定 A；全域不選 A 時，正則 A 消失，B 不變。
3. 全域選 A 時，正則 A 回來且啟用；取消後再次消失。
4. 重新整理酒館，再選 A，確認正則 A 完整回來。
5. A 套用時修改其正則，再卸下／套用，確認修改保留。
6. 再將同一正則綁到另一世界書；任一本套用即保留，兩本皆卸下才移除。
7. 如有不符，開綁定視窗按「重新讀取狀態」，提供即時選取／錯誤文字與酒館版本；不要先刪除備份。
